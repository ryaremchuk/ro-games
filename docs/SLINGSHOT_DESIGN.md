# Slingshot Birds — design doc

An Angry-Birds-style physics game adapted for a 3–4 year old. The child pulls a
slingshot and launches round birds at wobbly block towers to wake up sleeping
piggies. Every level is a small physics playground; the physics itself changes
as levels progress, so the child _feels_ gravity, mass, momentum, elasticity and
levers — not just taps.

Status: **v1 / test mode** — first playable for on-iPad testing, will be
iterated based on play sessions.

---

## 1. Why this game

- **Learning**: projectile arcs, toppling, mass, friction, bounce, levers, low
  gravity — all experienced through direct manipulation with a visible
  trajectory preview. This is the strongest "intuitive physics" teacher in the
  arcade.
- **Fun**: the destruction-cascade payoff of Angry Birds is universally loved;
  we keep the payoff and remove everything punishing.

## 2. Adaptation vs original Angry Birds

| Original                     | Our version                                                                               | Why                                  |
| ---------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------ |
| Precise drag on a small bird | Drag **anywhere on the left half** of the screen loads and pulls the sling                | 3yo fine-motor: no precise grab      |
| Limited birds, fail + retry  | **Unlimited birds**, auto-reload; level ends only in success                              | No-fail convention                   |
| Scores, stars, menus         | None. Level badge only (shared `reportLevel`)                                             | Pre-reader, no text/numbers pressure |
| Pigs get destroyed           | Sleeping piggies **wake up laughing** and float away on a balloon with confetti           | Positive framing, no harm imagery    |
| Invisible trajectory         | **Always-on dotted trajectory preview** while aiming                                      | This is the physics lesson           |
| Fixed physics                | Physics **changes with level themes** (materials, bounce, momentum, levers, moon gravity) | "Feel the physics" goal              |
| Camera scroll/zoom           | **Single fixed screen**, everything visible                                               | Toddler spatial simplicity           |

## 3. Core loop

1. Bird sits on the slingshot, blinking. Piggies snooze (zzz) in/on a block
   structure on the right.
2. Child touches anywhere on the left ~55% of screen and drags — the band
   stretches toward the drag vector (drag down-left → aim up-right), bird
   squashes, eyes widen, a rising creak tone plays, trajectory dots update live.
3. Release → launch (whoosh). **Tap during flight = one small flap boost
   upward** (chirp) — playful mid-air agency.
4. Impact: blocks knock, tumble, chain-react. Any meaningful contact with a
   piggy (direct hit OR a block falling on it — generous, low impulse
   threshold) frees it: it wakes, giggles (rising 3-note), spins, and floats
   off-screen on a balloon with a confetti puff.
5. Landed bird poofs into hearts after ~1s; the next bird hops onto the sling
   automatically. No action needed to continue.
6. All piggies freed → celebration (rainbow arc + confetti + arpeggio,
   ~2.5s) → level badge +1 → next level auto-builds with a fun "blocks drop
   into place" entrance.

### Forgiveness & soft-error details

- Pull below ~40 css px → bird hops back to the sling with a "boing" (no dud
  flights).
- Max pull is capped so the bird always stays on screen.
- A launch that frees no piggy = bird tumbles comically, dusts off — funny,
  never a buzzer/red flash.
- **Invisible aim assist**: after 5 consecutive piggy-less launches, each
  subsequent flight gets a gentle mid-air steering force toward the nearest
  piggy (never shown). Guarantees eventual success. Resets on any freed piggy.
- Idle 10s → bird chirps and hops, band wiggles (attract attention).

## 4. Levels: endless, procedural, theme-scheduled

Levels are generated by pure `logic.ts`: `generateLevel(levelNumber)` uses a
**seeded RNG (seed = level number)** → the same level is always the same
(replayable, testable). A hand-tuned schedule introduces one physics concept at
a time, two levels each, then mixes:

| Levels | Theme                                                                                                                                                   | Physics concept felt                                |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| 1–2    | First towers: 2–4 blocks, 1 piggy on top, close & exposed                                                                                               | pull strength → arc                                 |
| 3–4    | Tall skinny towers + dominos                                                                                                                            | toppling, chain reactions                           |
| 5–6    | Materials mix: stone blocks barely move, ice slides out                                                                                                 | mass & friction                                     |
| 7–8    | Trampolines (bouncy mushrooms) on the ground                                                                                                            | elasticity — bird can bounce over/into things       |
| 9–10   | Big loose balls near towers                                                                                                                             | momentum transfer — hit ball, ball rolls into tower |
| 11–12  | Seesaws: plank on a pivot; piggy or block on far end pops up when near end is hit                                                                       | levers                                              |
| 13–14  | **Moon levels**: dark starfield, gravity ≈ 40%, floaty slow arcs, higher bounces                                                                        | gravity itself                                      |
| 15+    | Rotate through all themes with ramp: more blocks (≤10), 2–3 piggies, piggies tucked under ledges / behind walls, theme combos (trampoline + moon, etc.) | mixing concepts                                     |

Difficulty numbers for a 4yo: piggies 1→3 max, blocks 2→10 max, structures
occupy the right ~45% of the screen, always at least one piggy reachable by a
direct parabola (generator guarantees; tested). Rounds should resolve in
roughly 1–2 minutes.

From level 5, the bird queue occasionally (≈ every 3rd launch) serves a **Big
Bird**: 1.8× radius, ~3× mass, deeper sounds, smashes through stone — the
child directly feels mass difference.

## 5. Materials (physics + look)

All bodies are Matter.js. Shared palette only; saturated actors on a
desaturated 2-stop gradient background (sky + soft hills; moon theme: dark
gradient + procedural stars).

| Material     | Color base                     | Density | Friction | Restitution               | Look/behavior                                                                              |
| ------------ | ------------------------------ | ------- | -------- | ------------------------- | ------------------------------------------------------------------------------------------ |
| Wood block   | orange `#FFA94D`               | 1.0     | 0.6      | 0.1                       | rounded rect, grain lines, sleepy face that goes 😮 when tumbling                          |
| Stone block  | ink-gray (lightened `#3D3A4B`) | 3.0     | 0.8      | 0.05                      | rounded rect, speckles; barely moves unless Big Bird                                       |
| Ice block    | teal `#4ECDC4`, translucent    | 0.7     | 0.05     | 0.15                      | shiny highlight; slides out from under stacks                                              |
| Trampoline   | pink `#FF8FAB`                 | static  | 0.5      | 1.4 (restitution on bird) | mushroom cap, squashes on bounce                                                           |
| Ball         | sky `#4D96FF`                  | 1.2     | 0.4      | 0.4                       | circle with star pattern, rolls satisfyingly                                               |
| Seesaw plank | wood + purple `#9B5DE5` pivot  | 1.0     | 0.6      | 0.1                       | constraint pivot at center                                                                 |
| Bird         | coral `#FF6B6B`                | 1.5     | 0.5      | 0.35                      | procedural blob + big white eyes + tiny beak + feet (hero = blob+face, never scaled emoji) |
| Big Bird     | purple `#9B5DE5`               | 4.5     | 0.5      | 0.25                      | same blob style, 1.8× radius, bushy brows                                                  |
| Piggy        | mint `#6BCB77`                 | 0.8     | 0.6      | 0.2                       | round blob, snout, closed eyes + floating "z z" until woken                                |

Slingshot: procedural Y-shaped wood post, two rubber-band lines to the bird,
band color ink `#3D3A4B`.

## 6. Art & feedback details

- Zero image assets: Phaser `Graphics` → `generateTexture` for blocks/bird/
  piggy/slingshot; emoji only for small props (confetti 🎈🎉 optional, ≤80 css
  px). Crisp at dpr 2 (copy balloon-pop retina recipe: canvas at css×dpr,
  `zoom: 1/dpr`, relayout on resize/orientation).
- Squash & stretch: bird squashes on pull, stretches on launch, splats slightly
  on landing. Blocks get 😮 faces mid-tumble.
- Trajectory preview: ~12 fading dots along the ballistic arc (analytic
  parabola from launch velocity + current gravity — ignores collisions; that's
  fine and still truthful pre-impact).
- Everything tappable reacts: tap idle piggy → it snores louder and rolls over;
  tap slingshot → band twangs; tap blocks in flightless moments → tiny wiggle.
- Celebration accepts input again after ~1s (convention).

## 7. Audio (Web Audio, `shared/audio.ts` `playTone` only)

- Pull: creak — short repeated low square tones rising in pitch with stretch.
- Launch: fast descending sine sweep (approx by 3 quick tones) + chirp.
- Flap boost: bright chirp (~880 Hz triangle).
- Wood knock: low square 150–220 Hz; stone thud: 80–120 Hz; ice: high glassy
  1200 Hz sine, short.
- Trampoline: boing (rising 200→600 Hz).
- Piggy freed: giggle = rising 3-note major arpeggio + pop.
- Level clear: 5-note celebration arpeggio (copy pattern from sibling games).
- Miss/tumble: soft low "whomp" — never harsh.

## 8. Technical plan

```
src/games/slingshot/
  SlingshotGame.tsx    # React wrapper: dpr config, aria-label, PhaserGame mount (copy balloon-pop shape)
  SlingshotScene.ts    # Phaser 4 scene, Matter physics, all rendering/input/audio
  logic.ts             # pure, no Phaser: level generation + tuning constants
  logic.test.ts        # Vitest, seeded
```

- **Registry entry** (required, Danger-enforced): id `slingshot`, title
  "Slingshot Birds", path `/slingshot`, color `#FFD93D` (unused by other
  tiles), emoji `🐦`.
- **Physics**: Phaser Matter (`physics: { default: 'matter' }`, gravity per
  level spec). Launch = set bird velocity from drag vector (no constraint
  needed). Enable body sleeping for perf. Piggy "hit" = collision with impulse
  above a very low threshold, or cumulative contact — be generous.
- **Coordinates**: work in backing pixels (css × dpr) like sibling scenes;
  scale all physics tuning by a `u = min(width, height)/base` unit so iPhone/
  iPad/portrait/landscape all play the same. Structures live in the right ~45%
  regardless of aspect; sling bottom-left.
- **`logic.ts` API** (pure, injectable RNG like sibling games):
  - `generateLevel(level: number, rng?: Rng): LevelSpec` — normalized 0..1
    coordinates; scene maps to screen.
  - `LevelSpec = { theme, gravityScale, birds: BirdKind[] (cycle), blocks:
{material, x, y, w, h, angle}[], piggies: {x, y}[], props: {kind:
'trampoline'|'ball'|'seesaw', ...}[] }`
  - `themeFor(level)` — the schedule table above.
  - Assist rule: `assistStrength(consecutiveMisses)` (0 below 5, then ramps).
  - Material constants table exported (used by scene, asserted by tests).
- **Tests** (`logic.test.ts`): determinism (same level → same spec); theme
  schedule matches table; block/piggy counts within 4yo caps and monotone-ish
  ramp; all bodies within 0..1 bounds and structures in right zone; at least
  one piggy ballistically reachable (closed-form parabola check with the
  level's gravity); assist ramp shape. No Phaser in tests (jsdom can't run it).
- **Level badge**: `reportLevel(n)` on each level start, `clearLevel()` on
  scene/React unmount (copy sibling wiring).
- **Cleanup**: destroy Matter world with the scene; no timers leaking after
  unmount; `PhaserGame` handles game destroy.

## 9. Acceptance checklist (v1)

- [ ] `npm run format:check`, `lint`, `typecheck`, `test`, `build` all pass.
- [ ] Tile appears on launcher; game loads as its own chunk; home button works.
- [ ] Drag-anywhere aiming with live trajectory dots; release launches; capped
      power; sub-threshold pull hops back.
- [ ] Tap-in-flight flap works.
- [ ] Towers tumble believably; piggies free generously (block-fall counts);
      celebration → auto next level; badge increments.
- [ ] Levels 1–14 visibly walk the theme table (materials, trampolines, balls,
      seesaws, moon gravity all appear); 15+ keeps generating.
- [ ] Unlimited birds auto-reload; invisible assist after 5 misses; idle nudge.
- [ ] No text shown to the child anywhere; sounds on every interaction; no
      red/error feedback.
- [ ] Works portrait + landscape, relayouts on resize, crisp on dpr 2.
